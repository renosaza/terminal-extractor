# terminal-extractor

Локальный MCP-сервер для совместной работы человека и агента в **Terminal.app и Ghostty на macOS**.

**Состояние: технический проект, не готовое приложение.** В репозитории описаны требования, предлагаемый стек, ограничения нативного подключения, контракты, приёмка и план реализации. Установщика, исполняемого сервера и подтверждённой runtime-совместимости пока нет.

Начать с [технического PRD](docs/product/prd.md), затем открыть [архитектуру](docs/architecture/README.md), [MCP-контракт](docs/architecture/mcp-contract.md) и [план реализации](docs/work/README.md). Полная навигация — [docs/index.md](docs/index.md).

Продукт должен подключаться к выбранной существующей вкладке/панели или явно создавать новую. Пользователь видит настоящее окно Terminal.app/Ghostty; агент получает текст, а не screenshots/OCR. Выбор приложения не зависит от режима подключения. Полная управляемая сессия и нативный доступ к старой вкладке имеют разные гарантии; подмена одного другим запрещена.

Карточки `docs/work/tasks/` — единственный источник состояния задач; GitHub Issues сейчас не дублируют этот план.
