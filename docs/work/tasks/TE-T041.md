# Fixture corpus и contract test harness

## Результат

Создать безопасные детерминированные shell/PTY/text fixtures и harness для schemas, state machines, cursors, ACL и capture projections.

## Приёмка

Ground truth ожидаемых bytes/state/code задан независимо от реализации. Fixtures не читают рабочие credentials и не меняют сеть/production. Unit/mock tests явно отделены от real macOS GUI cases. Реальные test commands добавлены в development guide с manifest.

## Проверка

NOT_RUN: запуск harness на чистом test tree, deliberate negative failures и golden mismatch. Никакого fake PASS от skipped tests; reproducible seeds/versions зафиксированы. AT-05/08/11/13/15/17, TE-C04/06/07.
