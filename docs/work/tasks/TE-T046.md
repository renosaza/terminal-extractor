# Установка, обновление и безопасное удаление

## Результат

Реализовать явный user-scoped setup/upgrade/removal приложения, optional per-user autostart и проверку tmux dependency без скрытого изменения окружения.

## Приёмка

Shell rc/terminal profiles/global AGENTS/user tmux config не меняются без отдельного согласия. Удаление runtime и данных выбирается раздельно; живые unrelated sessions не kill. Несовместимая schema update откатывается безопасно. Нет придуманной Homebrew formula.

## Проверка

NOT_RUN: clean install, existing config/rc, upgrade failure, uninstall с живыми sessions и отказ удаления логов. AT-18, TE-C06/07/08/09.
