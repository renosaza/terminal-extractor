# Проверить Codex и второй MCP-клиент

## Результат

Получить end-to-end interoperability report для двух реально установленных клиентов, включая точные config snippets и negotiated versions.

## Приёмка

Одинаковая sequence list/attach/execute/get/read/release работает в обоих приложениях. Long command не требует long tool timeout, request cancellation не kill. Неподдерживаемые resources/Tasks extension не ломают baseline. Client-specific UI permission не заменяет broker ACL.

## Проверка

NOT_RUN: real clients, короткий/длинный/неуспешный job, reconnection, malformed params и bounded output. Публиковать версии и проверенные snippets вместо generic guess. AT-16/17, TE-C04/06/07.
