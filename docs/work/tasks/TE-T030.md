# Реализовать read/status/log tools

## Результат

Подключить capabilities/list/read/command_get/last_command/log_read/search/content_get/wait/export к core models с правами и budgets.

## Приёмка

Status/last query никогда не запускают commands. Нет доступа к непереданным sessions или arbitrary paths. Polling bounded, cursor gaps/uncertainty сохраняются. Resource optional, те же данные доступны tools; fallback text не дублирует большой structured content.

## Проверка

NOT_RUN: контрактные fixtures, ACL на каждом read path, slow consumer, wait timeout/cancel, expired cursor и concurrent writes. AT-04/05/07/08/10/16, TE-C04/05/07.
