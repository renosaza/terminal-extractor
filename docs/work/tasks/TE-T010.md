# Terminal.app: явное новое окно и binding

## Результат

Реализовать native-new и общий launch path для будущего managed attach command в обычном Terminal.app.

## Приёмка

Запуск только по explicit new/permission; ровно созданная вкладка связывается с registry до разрешения ввода. Existing не перезапускается. Initial cwd/launch arguments передаются безопасно и не становятся arbitrary AppleScript source; user profile/font/theme сохранены.

## Проверка

NOT_RUN: app closed/running, несколько окон, launch failure/timeouts, необычный cwd с пробелами/quotes, окно закрыто до ready. Нельзя тихо выбрать соседнее. AT-01/02/03, TE-C02/03/06.
