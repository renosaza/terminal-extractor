# Durable intents, dedup и indeterminate recovery

## Результат

Сохранять request intent/digest/target/lease до physical dispatch, возвращать тот же record при retry и не повторять неоднозначно доставленный ввод.

## Приёмка

Same request/digest не создаёт вторую команду; changed digest даёт conflict. Crash после input до ack становится indeterminate, а не replay. Evidence reconciliation может восстановить status, но не заявляет exactly-once произвольного GUI side effect. Revoke отменяет только недоставленное.

## Проверка

NOT_RUN: fault injection на каждой границе persist/dispatch/ack/end; reconnect с stale generation; concurrent duplicate calls. AT-11/12, TE-C03/04/07.
