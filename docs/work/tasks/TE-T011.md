# Terminal.app: verified line transport и capability limits

## Результат

Подключить проверенный addressed line-submission к command engine adapter, не выдавая его за универсальный raw-key transport.

## Приёмка

Verified idle shell/empty input prerequisites проверяются. Literal text не интерполируется в executable script. Unsupported no-Enter/control keys отклоняются до side effect. Busy REPL/SSH не получает скрытый bootstrap или новую shell-команду. Delivery timeout может стать indeterminate.

## Проверка

NOT_RUN: text/quotes/newline, пользовательская неполная строка, busy process, denied permission и delayed event. Проверить отсутствие лишнего Enter и fallback в активное окно. AT-05/06/09/11, TE-C02..04/09.
