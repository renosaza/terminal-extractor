# Ghostty: existing/new и интерактивная приёмка

## Результат

Проверить complete native adapter на реальных версиях приложения и записать поддерживаемые операции без переноса main-source claims на старые релизы.

## Приёмка

Existing SSH/REPL fixture продолжается, new явно создаётся. Keys/paste направлены в выбранный split при смене focus. Screen/export ограничения и clipboard side effect опубликованы. Нет claim о полном непрерывном native логе.
Проверить внутренние splits Ghostty: адресное создание/закрытие и пользовательские Cmd+D/Cmd+W на отдельном окне, stale surface после закрытия и отсутствие fallback к соседнему split. Матрица input включает Tab, Shift+Tab, Control/Option/Command/Shift, их сочетания и layout-dependent Option-символы; app shortcuts и terminal bytes фиксируются раздельно.

## Проверка

PARTIAL feasibility на Ghostty 1.3.1: одноразовый GUI probe проверил split create/close, stale ID, адресный Tab без ввода в соседний split, Shift+Tab и перечисленные в TE-T013 сочетания. AppleScript `send key` с Cmd+D/Cmd+W не выполнил соответствующие пользовательские shortcuts; `perform action new_split:right/close_surface` сработал. Физические хоткеи, другие раскладки и полная продуктовая приёмка AT-01..04/09/14/15/17, Unicode вне literal paste, alternate screen, scrollback clear, split reuse, permission denial — NOT_RUN. Сохранить commit/version/results, без user content. TE-C01..04/06/07.
