# Ghostty: новое окно/вкладка и launch configuration

## Результат

Использовать verified surface configuration для explicit new и безопасного запуска managed attach-client в нужном окне.

## Приёмка

Initial cwd/command/environment не изменяют глобальный config, не наследуют тайно credentials агента. Возвращается только созданный binding после readiness. App default changes не трогают existing session. Ошибка launch не открывает другой terminal.

## Проверка

NOT_RUN: приложение закрыто/запущено, несколько windows, slow shell startup, failure/close before ready и unusual cwd. AT-01/02/03/18, TE-C02/03/06.
