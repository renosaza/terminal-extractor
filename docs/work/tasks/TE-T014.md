# Ghostty: новое окно/вкладка и launch configuration

## Результат

Проверить surface configuration для explicit new и безопасного запуска managed attach-client в нужном окне.

## Приёмка

Проверить фактическую поддержку initial cwd/command/environment на установленной версии: TE-T002 подтвердил new window/tab и IDs, но не launch configuration. Параметры не изменяют глобальный config и не наследуют тайно credentials агента. Возвращается только созданный binding после readiness. App default changes не трогают existing session. Ошибка launch не открывает другой terminal.

## Проверка

NOT_RUN: приложение закрыто/запущено, несколько windows, slow shell startup, failure/close before ready и unusual cwd. AT-01/02/03/18, TE-C02/03/06.
