# Restart, sleep/wake и failure reconciliation

## Результат

Согласовать session/command/capture/grant state после gateway/host/recorder/app crash, sleep/wake и storage failure.

## Приёмка

Живой shell не означает gapless log. Old generation/lease не возрождается; неизвестная delivery не replay. Last view close блокирует ввод, но не уничтожает pane неявно. После reboot не обещается восстановление памяти process. Diagnostics показывают причину и безопасный remedy.

## Проверка

NOT_RUN: fault matrix на lifecycle boundaries, power-loss storage fixture, app instance replacement и interrupted command. AT-11/12/14/17, TE-C03/04/07.
