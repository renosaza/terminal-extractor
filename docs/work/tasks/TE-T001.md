# Проверить API установленного Terminal.app

## Результат

Создать безопасный probe dictionary, адресного чтения и ввода в отдельную тестовую вкладку. Записать OS/app versions и dictionary hash, поддерживаемые selectors и неизвестные возможности.

## Приёмка

Проверены window/tab/TTY mapping, retained contents/history, line submission и наличие либо отсутствие безопасного no-Enter/control-key пути. Доказано, что existing fixture сохраняет PID/переменную. Не использовать do shell script как замену живой вкладке или focus injection. Full native interactive gate либо закрыт evidence, либо остаётся явно открытым.

## Проверка

NOT_RUN: две вкладки, смена focus, quotes/newlines, busy REPL и idle shell; записать фактическую семантику каждой операции. Ничего не вводить в рабочие окна. AT-02/03/09/17, TE-C01..04/09.
