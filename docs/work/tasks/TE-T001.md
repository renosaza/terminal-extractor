# Проверить API установленного Terminal.app

## Результат

Создать безопасный probe dictionary, адресного чтения и ввода в отдельную тестовую вкладку. Записать OS/app versions и dictionary hash, поддерживаемые selectors и неизвестные возможности.

## Приёмка

Проверены window/tab/TTY mapping, retained contents/history, line submission и наличие либо отсутствие безопасного no-Enter/control-key пути. Доказано, что existing fixture сохраняет PID/переменную. Не использовать do shell script как замену живой вкладке или focus injection. Full native interactive gate либо закрыт evidence, либо остаётся явно открытым.

## Проверка

PARTIAL: словарь и версии, отдельные fixture-окна, адресный ввод/чтение, смена focus, quotes/newlines и REPL проверены. Две вкладки в одном окне и адресный no-Enter/control-key ввод — `NOT_RUN`. Ничего не вводилось в рабочие окна. AT-02/03/09/17, TE-C01..04/09.

## Фактический результат и продолжение

На macOS 27.0 (26A428) установлен Terminal.app 2.15 (build 488). `python3 probes/dictionaries.py` прочитал встроенный `Terminal.sdef`, SHA-256 `efc515ecd1bee050284942655a76654c84ff4c77f6cbe4704d7aafbabe8a92af`. Словарь объявляет `window.id`, `window.tabs`, `tab.tty`, `tab.contents`, `tab.history`, `tab.busy` и `do script` с параметром `in` типа `tab`/`window`. У `tab` нет собственного стабильного `id`; `window.index` описан как порядок спереди назад. Отдельной команды raw paste или `send key` словарь не объявляет. Это `known` только для декларации API, не для фактической доставки или полноты истории.

После разрешения Apple Events открыты два отдельных [fixture-окна](../../../probes/terminal-app/fixture.command) через `open -a Terminal`: `window id` 51824/51826, TTY `/dev/ttys007`/`/dev/ttys008`. Ввод `do script ... in selected tab of window id 51824` сохранил `pid=80633` и `TE_E01_VAR=alive`; при активном втором окне ввод и чтение первого остались адресными. Quotes и две строки прошли через `do script` как line submission. После 60 строк `contents` содержал последнюю (`fill60`), но не первую и не fixture marker; `history` содержал все три. Это retained text, не доказательство полного потока. В `python3 -i -q` `do script` доставил `print(...)`; после выхода Python `busy` остался `true` в idle shell, поэтому это поле не подтверждает завершение команды. Оба fixture-окна закрыты.

`make new window` возвращал -10000 и оставил пустое окно 51769 без вкладок; `do script` и `make new tab` для него не сработали. Окно 51769 осталось в списке после команды закрытия, рабочие окна не затрагивались. `sdef` из активного Command Line Tools не запускается без полного Xcode; probe читает встроенный файл напрямую. Safe native no-Enter/control-key selector не найден и runtime gate остаётся открытым. Проверенный revision: текущая ветка `te-e01` до фиксации этих результатов.
