# Dedicated tmux backend и lifecycle

## Результат

Создавать/регистрировать pane в отдельном private socket namespace с минимальной собственной config и долгоживущим shell owner.

## Приёмка

User tmux server/config не затронуты. На each command новый shell не создаётся. Capture gate существует до workload. Registry связывает pane/socket/generation; закрытие одного session не вызывает kill-server. Existing arbitrary pane требует локальной регистрации.

## Проверка

PARTIAL feasibility, 2026-09-24: `sh probes/tmux/probe.sh` PASS на отдельном private socket и `/dev/null` config: два fixture sessions, capture gate до test workload, закрытие первой по точному `=session-name` сохраняет pane ID/PID второй. Голое имя `te-probe` в `has-session -t` ошибочно нашло `te-probe-other` по префиксу; для lifecycle нужен exact target. Продуктовый owner/registry, gateway disconnect, pane exit/recreate, namespace collision, отсутствующий tmux и реальная GUI pane — NOT_RUN. Не считать probe реализацией TE-T017. AT-02/03/12, TE-C02/03/06/07.

PARTIAL implementation, 2026-09-24, checked code revision `f232de0`: `ManagedTmux` создаёт только detached служебную pane с `/bin/sleep` в отдельном socket namespace и `/dev/null` config. Binding содержит явные session ID/generation, tmux session/pane ID и socket path; revalidate проверяет owner/mode/inode namespace и точный pane, close адресует сохранённый session ID и не делает kill-server. `swift run TermexManagedTmuxCheck` PASS: два fixture bindings, stale generation, missing tmux, socket collision и закрытие одной без смены PID второй. `swift run TermexRegistryCheck`, `swift run TermexConfigCheck` и `git diff --check` PASS. Capture gate, долгоживущий shell, GUI attach/consent, gateway disconnect, pane exit/recreate и таймаут с неоднозначным server-side результатом — NOT_RUN. При таком таймауте есть best-effort cleanup по точному имени и найденному session ID, но отсутствие осиротевшей pane не доказано; private namespace следует сохранить для диагностики. Это не пользовательская сессия и не снимает блокер чтения истории existing Ghostty pane.
