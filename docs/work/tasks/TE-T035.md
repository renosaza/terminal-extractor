# ACL-aware compact cache и exact original retrieval

## Результат

Ввести versioned cache key с content/session/privacy/grant/algorithm/policy/budget и надёжную ссылку compact -> разрешённый original interval.

## Приёмка

Нет cross-session leakage/cache discovery. Revoke/delete/private epoch инвалидируют entry и повторное чтение. Headroom reference не даёт самостоятельного доступа. Expired original обозначается явно; не генерируется реконструкция, выдаваемая за исходник.

## Проверка

NOT_RUN: две сессии с одинаковым text hash и разными grants, race revoke/read, retention expiration, policy/algorithm upgrade. Original bytes совпадают с archive. AT-10/13/14, TE-C04/05/07.
