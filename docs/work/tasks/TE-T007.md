# Local identity, grants и writer leases

## Результат

Ввести peer-checked private IPC, server-side client identity, отдельные read/control/close/clipboard grants и один agent writer на session.

## Приёмка

ClientInfo/name/request fields не дают прав. Grants привязаны к session generation и локальному consent; ревокация увеличивает epoch до cleanup. ACL применяется к read/search/original retrieval и mutations. Нет permissive socket/содержимого секретов в diagnostics.

## Проверка

PARTIAL: `swift build`, `swift run TermexConfigCheck`, `python3 Tests/integration/check.py` PASS. Проверены owner/mode socket, same-UID gateway, bounded/slow frame, отказ при лишнем `clientInfo` и отсутствие IPC-подключения при неизвестном `TERMEX_*`. Cross-UID отказ отдельно NOT_RUN: тестовый процесс работает под одним UID. Два клиента с grants, stale token/epoch, cross-session read, expired lease и race revoke/dispatch — NOT_RUN до registry и локального consent. AT-10/11/14, TE-C03/06/07.

## Фактический результат и продолжение

`LocalIPC` проверяет peer effective UID через `getpeereid` после connect/accept; при отказе host не завершает listener. Gateway валидирует имена env preferences до подключения и передаёт только три документированных ключа. Это проверка локального IPC, а не выдача terminal access: `terminal_access=false`, нет grants, writer lease или локального consent UI. Same-UID процесс не изолирован этим механизмом.

Следующий шаг — registry с session generation и постоянной identity клиента, затем отдельные grants/read-control-close-clipboard и revoke/lease проверки до любых session tools. Проверена ревизия `e74c9dc` на ветке `te-e02`.
