# Реализовать namespaced zsh integration

## Результат

Поставить opt-in hooks/bootstrap и authenticated local start/end/readiness events со shell epochs и sequence.

## Приёмка

Сохраняются startup files, ZDOTDIR и hooks; `$?` снимается первым. Existing busy shell не получает bootstrap. Выход/exec/потеря канала понижают evidence. Stream fence protocol задан независимо от подключения recorder и не доверяет произвольным OSC. Uninstall не удаляет пользовательские hooks.
