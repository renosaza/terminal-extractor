# Ghostty: безопасный opt-in text export

## Результат

Реализовать addressed write_screen_file/write_scrollback_file copy action, private file validation и честную clipboard transaction.

## Приёмка

Нет OCR/screenshots/paste filepath/open editor. Согласие отдельно от read grant. Path не принимается без owner/regular-file/no-symlink/size/fstat проверки; arbitrary file read запрещён. Screen и scrollback — разные non-atomic snapshots, не полный stream. Clipboard конфликт fail closed; чужое изменение не перезаписывается намеренно. Остаточная non-atomic race и watchers exposure указаны.

## Проверка

После изменения порядка восстановления и окна согласия повторный вызов тоже вернул снимок; хеши всех доступных типов и байтов clipboard до/после совпали (`clipboard_exact=True`). Текст экрана и содержимое clipboard в тестовый вывод не попадали. Отдельный host завершился по SIGTERM без предупреждения Swift о гонке. Конкурентный clipboard writer, deferred provider, timeout, Stop во время export и большой реальный export — NOT_RUN. Оригинальный файл не удаляется. AT-04/14/17, TE-C01/04/06/07/09.

PARTIAL, 2026-09-24: в ревизиях `d3a77d5` и `4765d25` `swift build`, `swift run TermexExportRaceCheck`, `python3 Tests/integration/check.py`, `git diff --check` — PASS. Синтетический тест использует только именованный clipboard и временный fixture: блокирует export action, отзывает разрешение, затем подтверждает отказ до чтения файла и восстановление прежнего значения. Отдельный ранний конфликт с чужим writer сохраняет новое значение. Host Stop проверен при восьми открытых IPC clients и при частичном активном запросе: соединения закрыты, новый client после Stop работает. Реальный Ghostty export одновременно со Stop, поздняя запись другого clipboard writer между финальной проверкой и restore, deferred provider и большой export — NOT_RUN. Тесты не доказывают атомарную защиту clipboard и не выводят пользовательское содержимое.

## Фактический результат и продолжение

Добавлен одноразовый `terminal_screen` для выбранной Ghostty surface при локальном read scope и отдельной отметке clipboard export. UI больше не выдаёт неиспользуемый control scope. Опция `native_ghostty_clipboard_export` в private config по умолчанию выключена. Gateway хранит token внутри connection; host проверяет peer executable, token, generation, scope и epoch до адресного действия и после него. Файл открывается через private temp directory FD с `O_NOFOLLOW`, ограничением размера и повторным `fstat`. Живой тест выявил каталог Ghostty `0755` внутри private temp root `0700` и эквивалентные пути `/var` и `/private/var`; validator принимает этот layout, но отклоняет group/other writable directory. Живой ответ >255 байт выявил trap при упаковке заголовка IPC; исправлено через `UInt8(truncatingIfNeeded:)` и покрыто 300-байтовым frame check. Clipboard сохраняется в памяти и восстанавливается при узнаваемом пути и неизменном `changeCount`/path до проверки нового каталога и файла. Универсального атомарного CAS нет; при ошибке до узнавания пути или конфликте чужой записи восстановление не гарантировано.

Установленный Ghostty 1.3.1 создаёт два не закрываемых directory FD на успешный export по [исходнику релиза](https://github.com/ghostty-org/ghostty/blob/v1.3.1/src/Surface.zig#L5494-L5497) и [TempDir](https://github.com/ghostty-org/ghostty/blob/v1.3.1/src/os/TempDir.zig#L20-L63). Продукт ограничивает export до одного раз в 5 секунд и 64 на app instance за жизнь host; это ограничение не переживает перезапуск host. Частый polling на этом релизе не поддерживается. По [реализации действия](https://github.com/ghostty-org/ghostty/blob/v1.3.1/src/Surface.zig#L5992-L6112) успешный `write_screen_file:copy` создаёт файл до установки clipboard path. Проверка единственного нового каталога отсекает обычный параллельный export; чужое удаление или подмена файлов тем же UID остаётся вне доказуемой привязки. Следующий шаг — живой Stop во время export с отдельным локальным согласием на тестовую pane и проверкой clipboard без вывода содержимого; отдельно реализовать `write_scrollback_file`, затем оценить исправленный релиз Ghostty.
