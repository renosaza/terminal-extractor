# Ghostty: безопасный opt-in text export

## Результат

Реализовать addressed write_screen_file/write_scrollback_file copy action, private file validation и честную clipboard transaction.

## Приёмка

Нет OCR/screenshots/paste filepath/open editor. Согласие отдельно от read grant. Path не принимается без owner/regular-file/no-symlink/size/fstat проверки; arbitrary file read запрещён. Clipboard конфликт fail closed; чужое изменение не перезаписывается намеренно. Остаточная non-atomic race и watchers exposure указаны.

## Проверка

NOT_RUN: конкурентный clipboard writer, deferred provider, timeout, stale/malicious path и большой export. Snapshot timestamps/coverage точны; нет auto-delete чужих files. AT-04/14/17, TE-C01/04/06/07/09.
