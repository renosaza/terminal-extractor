# Readiness и execution state machine

## Результат

Реализовать literal execute в current shell с command ID, bounded wait, evidence-based running/completed/unknown и отдельным delivery state.

## Приёмка

Непустая ZLE строка/continuation/busy программа не перезаписываются. Command start/end согласованы с raw fences; silence не завершает command. Нет eval/subshell/new shell/hidden cwd. Queue disabled default; wait timeout не kill; exit_code nullable и success не равен достижению цели пользователя.

## Проверка

NOT_RUN: быстрые/долгие/безвыводные/ненулевые команды, aliases/cd/export, multiline, exec/exit, spoofed marker и boundary loss. AT-05/06/09, TE-C02..04/07.
