# Исследовать и подключить optional Headroom worker

## Результат

Зафиксировать реальный Headroom release/API/dependencies и построить isolated bounded worker для selected text fragments, не proxy всей агентской переписки.

## Приёмка

Core запускается без Python/Headroom. Нет сетевых моделей, автозагрузки weights или передачи API credentials. Worker не изменяет metadata и не управляет terminal. Error/timeout возвращает builtin bounded view. Наш archive остаётся authoritative для originals независимо от CCR.

## Проверка

NOT_RUN: pinned package smoke test, no-network environment, worker crash/timeout/invalid response, cold/warm latency. Отказ от непригодной интеграции оформляется evidence/ADR, не fake success. AT-13, TE-C05/06/07.
