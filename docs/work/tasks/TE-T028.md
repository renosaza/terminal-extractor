# Quotas, retention, gaps и invalidation

## Результат

Ввести age/size quotas, tombstones, private omissions и удаление связанных cache refs по grant/privacy epoch.

## Приёмка

Удалённые диапазоны не выглядят пустым полным логом. Earliest cursor, reason и gap manifest доступны. Active command metadata сохраняет expired output refs. Disk full не вызывает скрытое удаление чужих файлов. Политика/consent видны до включения recording.

## Проверка

NOT_RUN: маленькие quotas, active command rotation, private range, revoke/delete во время чтения, recovery после disk full. AT-08/12/14/18, TE-C04..07.
