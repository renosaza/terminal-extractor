# Ghostty: surface discovery и адресный input

## Результат

Реализовать version-probed hierarchy и ввод literal paste/keys в exact terminal surface через native scripting API.

## Приёмка

IDs/instance проверяются перед dispatch; title/index не route key. Text не печатается посимвольно через текущую раскладку. Enter отдельный; unsupported key отклонён; partial operation delivery отражена. Existing process не заменяется.

## Проверка

NOT_RUN: windows/tabs/splits, focus в другом приложении, русская/латинская раскладка, modifiers, rename/reorder и target close. AT-02/03/09/15/17, TE-C01..04/07.
