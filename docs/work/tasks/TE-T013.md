# Ghostty: surface discovery и адресный input

## Результат

Реализовать version-probed hierarchy и ввод literal paste/keys в exact terminal surface через native scripting API.

## Приёмка

Возвращённые window/tab/surface IDs, app instance и generation проверяются перед dispatch; title/index не route key. Ghostty 1.3.1 не объявляет surface `pid`/`tty`, более новые свойства требуют отдельного version probe. Text не печатается посимвольно через текущую раскладку. Enter отдельный; unsupported key отклонён; partial operation delivery отражена. Existing process не заменяется.

## Проверка

PARTIAL: read-only Ghostty 1.3.1 enumeration и exact resolution проверены на двух окнах; закрытый target отклонён. `swift build`, `python3 Tests/integration/ghostty_discovery.py` PASS. Tabs/splits в одном окне, app restart, rename/reorder, focus в другом приложении, literal paste/keys, раскладки/modifiers, generation и разрешённый dispatch — NOT_RUN. AT-02/03/09/15/17, TE-C01..04/07.

## Фактический результат и продолжение

[GhosttyDiscovery](../../../Sources/TermexCore/GhosttyDiscovery.swift) использует read-only Apple Events к PID запущенного Ghostty, перечисляет window/tab/surface IDs и сверяет app instance. Локальный `--resolve-ghostty` требует все ID; фокус, title и index не выбирают цель. Содержимое сессий и input недоступны. Следующий шаг — registry, локальный consent и адресный input только после grants. Проверена ревизия `58c1323` на ветке `te-e02`.
