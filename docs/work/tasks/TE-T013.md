# Ghostty: surface discovery и адресный input

## Результат

Реализовать version-probed hierarchy и ввод literal paste/keys в exact terminal surface через native scripting API.

## Приёмка

Возвращённые window/tab/surface IDs, app instance и generation проверяются перед dispatch; title/index не route key. Ghostty 1.3.1 не объявляет surface `pid`/`tty`, более новые свойства требуют отдельного version probe. Text не печатается посимвольно через текущую раскладку. Enter отдельный; unsupported key отклонён; partial operation delivery отражена. Existing process не заменяется.

Адресный `send key` проверяется отдельно от shortcuts самого Ghostty: Cmd+D/Cmd+W могут менять split/tab/window, а не отправлять bytes приложению. Проверить Tab, Shift+Tab, Control/Option/Command/Shift и их сочетания, press/release, Option-символы на фактической раскладке. Для каждого результата различать Apple Event accepted, действие GUI, bytes в выбранной surface и отсутствие ввода в соседнюю; не объявлять доставку комбинации по одному success-ответу.

## Проверка

PARTIAL: read-only Ghostty 1.3.1 enumeration и exact resolution проверены на двух окнах; закрытый target отклонён. `swift build`, `python3 Tests/integration/ghostty_discovery.py` PASS. В отдельном одноразовом окне `python3 probes/ghostty/keys_probe.py` PASS: адресный Tab в каждом из двух splits не попал соседу; закрытый split не разрешился как соседний; `perform action new_split:right/close_surface` создали/закрыли ровно выбранный split, тестовое окно закрыто. В raw fixture `send key` дал Tab=`09`, Shift+Tab=`1b5b5a`, Ctrl+C=`03`, Ctrl+Option+A=`1b01`; `input text "é"` дал UTF-8 `c3a9`. Обычные A/E/digit2, Shift+A, Option+A/Option+digit2/Option+E и их проверенные сочетания, Control+Tab, Control+Shift+Tab и Command+A не дали байтов в окне наблюдения 0,2 с. Последовательность Option+E,E также не дала байтов; поскольку обычная E тоже не дала байтов, отдельный эффект Option/«мёртвой» клавиши пока не установлен. `send key` с Cmd+D/Cmd+W не изменил число splits; Shift+Tab action release не дал байтов. Среда: Ghostty 1.3.1, раскладка RussianWin, `macos-option-as-alt=left`; результаты не доказывают поведение физических хоткеев или других раскладок. App restart, rename/reorder, focus в другом приложении, generation, consent и продуктовый dispatch — NOT_RUN. AT-02/03/09/15/17, TE-C01..04/07.

## Фактический результат и продолжение

[GhosttyDiscovery](../../../Sources/TermexCore/GhosttyDiscovery.swift) использует read-only Apple Events к PID запущенного Ghostty, перечисляет window/tab/surface IDs и сверяет app instance. Локальный `--resolve-ghostty` требует все ID; фокус, title и index не выбирают цель. В репозитории есть только локальный GUI probe ввода, не продуктовый input. Следующий шаг — registry, локальный consent и адресный input только после grants. Реализация discovery проверена на ревизии `58c1323`; результаты GUI probe записаны в этой карточке на ветке `te-e02`.
