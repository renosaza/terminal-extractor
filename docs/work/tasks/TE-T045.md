# Собрать app/CLI/helper комплект с устойчивой identity

## Результат

Подготовить bundle layout и reproducible build, затем подписать/notarize при наличии явно разрешённой реальной signing identity.

## Приёмка

Host/helper TCC identity стабильна; entitlements минимальны; executable paths соответствуют клиентским config. Dependency versions/lockfile/SBOM либо эквивалентный manifest доступны. Не придуманы Team ID/certificates и не записаны credentials в repo.

## Проверка

NOT_RUN: clean build, codesign/notarization verification при доступных правах, first-run TCC и update identity regression. Без signing доступа task blocked, не fake signed. AT-17/18, TE-C06/07/09.
