# Builtin bounded compact representation

## Результат

Реализовать размерные лимиты, range/head/tail selection, exact-repeat folding и source refs без обязательного ML.

## Приёмка

IDs/state/evidence/coverage/exit code неизменны; current interactive screen и executable content не сжимаются с потерями. Есть original reference, omitted range/count и estimated-token label. Hard byte cap действует и при compressor failure; нет молчаливой truncation.

## Проверка

NOT_RUN: ошибка в середине лога, уникальные числа среди повторов, Unicode, огромная строка, exact mode paging и protected fields. AT-08/13/15, TE-C04/05/07.
