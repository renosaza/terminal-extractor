# Финальный аудит поставки и разрешение выпуска

## Результат

Собрать release manifest: checked commit, artifacts/hashes, tested matrix, acceptance report, known limitations, dependency versions и owner decision по scope выпуска.

## Приёмка

Runtime claims не превосходят evidence. Незавершённый Existing full-control не скрыт словом «полностью». Все обязательные security/identity/replay/privacy gates закрыты либо выпуск явно ограничен и не закрывает соответствующие карточки. Publish/signing credentials используются только с нужными правами.

## Проверка

NOT_RUN: artifact verification, smoke install, docs-to-code/FR-to-AT audit и проверка актуальных open blockers. Записать release decision и проверяющего; не выдумывать independent review. AT-01..18, TE-C01..09.
