# Take control, Stop/revoke и private mode

## Результат

Реализовать локальный быстрый отзыв агента и privacy transition, не зависящие от ответа MCP-клиента/helper/compressor.

## Приёмка

Сначала меняется grant/lease epoch, затем отменяется очередь. Уже доставленное не считается отозванным; running program не kill по умолчанию. Private mode прекращает reads/capture/export/text persistence; resume не реимпортирует всё ещё видимый secret. Возврат агента требует fresh grant/read.

## Проверка

PARTIAL: `swift build`, `swift run TermexRegistryCheck`, `python3 Tests/integration/check.py` PASS. IPC Stop и `termex-host --stop` увеличивают epoch до удаления grants; повторный Stop меняет epoch, host остаётся доступным. Начавшийся до Stop consent dialog не может записать grant после него из-за сравнения epoch. Hung helper/worker, реальный выбор во время Stop, partial dispatch, queued actions, synthetic secret, visible secret on resume и stale cache retrieval — NOT_RUN. Input/read dispatch, очередь и privacy mode пока отсутствуют. AT-10/12/14, TE-C04..07.

## Фактический результат и продолжение

Локальный CLI Stop доступен владельцу private socket и не зависит от MCP. Он отзывает все connection grants в памяти host, не закрывая чужие приложения и не обещая отмену уже доставленного действия. Видимый menu-bar Stop и per-session privacy transition ещё нужны. Изоляция от злонамеренного процесса того же UID пока не доказана.
