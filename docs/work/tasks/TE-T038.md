# Take control, Stop/revoke и private mode

## Результат

Реализовать локальный быстрый отзыв агента и privacy transition, не зависящие от ответа MCP-клиента/helper/compressor.

## Приёмка

Stop прекращает обмен через текущие client sockets и инвалидирует grants до подтверждения; будущая очередь действий должна отменяться. Уже доставленное не считается отозванным; running program не kill по умолчанию. Private mode прекращает reads/capture/export/text persistence; resume не реимпортирует всё ещё видимый secret. Возврат агента требует fresh grant/read.

## Проверка

PARTIAL: `swift build`, `swift run TermexRegistryCheck`, `python3 Tests/integration/check.py` PASS. Private Stop socket и `termex-host --stop` увеличивают epoch до удаления grants; повторный Stop меняет epoch, host остаётся доступным. Stop проверен при восьми занятых основных IPC слотах. Начавшийся до Stop consent dialog не может записать grant после него из-за сравнения epoch. Hung helper/worker, реальный выбор во время Stop, partial dispatch, queued actions, synthetic secret, visible secret on resume и stale cache retrieval — NOT_RUN. Input, непрерывный read/journal, очередь и privacy mode пока отсутствуют; bounded Ghostty screen read уже есть. AT-10/12/14, TE-C04..07.

PARTIAL, код `4765d25`: `TermexExportRaceCheck` синтетически проверил отзыв при заблокированном export action и отказ до чтения файла; `Tests/integration/check.py` подтвердил прекращение обмена с восемью idle clients и активным partial-frame client до подтверждения Stop. Живой Stop во время реального Ghostty export — NOT_RUN. Уже записанные в socket байты не отзываются задним числом.

PARTIAL, 2026-09-24, код `ac44210`: после отдельного локального read + clipboard-export согласия на выбранную тестовую Ghostty pane начат один реальный `terminal_screen(view=screen)`. Это подтверждает Stop при незавершённом живом запросе после создания файла и отсутствие выдачи текста в этом исходе. Момент возврата Ghostty Apple Event относительно Stop не измерялся; его отмена не доказана. Повторного частого экспорта не проводилось.

## Фактический результат и продолжение

Локальный CLI Stop доступен владельцу отдельного private socket и не зависит от MCP или пула клиентов. Он вызывает `shutdown` текущих gateway sockets перед повышением grant epoch, отзывает все connection grants в памяти host и не закрывает чужие приложения. `close` происходит позднее при удалении клиента. Уже помещённые в socket байты могут быть дочитаны после подтверждения Stop; начатый Ghostty Apple Event не отменяется, но повторная проверка grant не позволяет выдать новый read result. Синтетическая гонка export/revoke и живой Stop при незавершённом screen request после создания файла проверены; пересечение именно с выполняющимся Apple Event не доказано. Видимый menu-bar Stop и per-session privacy transition ещё нужны. Изоляция от злонамеренного процесса того же UID пока не доказана.
