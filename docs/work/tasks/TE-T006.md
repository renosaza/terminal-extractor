# Настройки приложения и режима подключения

## Результат

Реализовать versioned local config, env overrides и independent terminal_app/attach_policy/new_session_backend.

## Приёмка

Terminal.app/Ghostty выбираются без смены API; existing/new/ask не подменяют друг друга. Security limits/allowed_apps не расширяются env клиента. Неверный enum/unknown key отклоняется, сохранение atomic. Изменение default не переносит живые bindings и не меняет user profiles.

## Проверка

PARTIAL: матрица двух apps × трёх attach policies × двух backends, defaults, env precedence, denied env policy expansion, unknown/invalid/corrupt JSON и atomic save проверены `swift run TermexConfigCheck`. Host-side allowed_apps и ответ MCP `terminal_capabilities` проверены `python3 Tests/integration/check.py`. Отсутствующее приложение, denied TCC, живые bindings/grants и UI изменения конфига — `NOT_RUN`. Развёрнутой предыдущей схемы нет; unsupported version отклоняется, migration/rollback не заявляется. AT-01/02/18, TE-C02/03/06/07.

## Фактический результат и продолжение

[LocalConfig](../../../Sources/TermexCore/LocalConfig.swift) принимает versioned JSON в private file, заполняет пропущенные поля defaults, отклоняет неизвестные ключи/enum и сохраняет через временный `0600` файл и atomic rename. Host загружает локальный config при старте и применяет только три разрешённых env preferences от gateway; выбранное приложение должно входить в локальный `allowed_apps`. `terminal_capabilities` возвращает фактический выбор с `terminal_access=false`. `new`/`native` пока не запускают окно и не выдают права. CLI host допускает `--config` только как абсолютный локальный путь; отсутствие явно указанного файла — ошибка без fallback.

Следующий шаг — TE-T007 grants и TE-T008 registry; после них проверить изменение default при живой session, наличие приложений/TCC и локальный UI update. Проверено на ветке `te-e02` до итогового commit: `swift build`, `swift run TermexConfigCheck`, `python3 Tests/integration/check.py` PASS.

На текущем Command Line Tools `swift test` дважды не собрал test target: сначала не найден `TestingMacros`, затем модуль `XCTest`. Поэтому конфиг проверяется исполняемым `TermexConfigCheck` без внешнего test framework; это ограничение этого стенда, не вывод о других Xcode installations.
