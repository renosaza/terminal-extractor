# Paging, search, exact retrieval и export

## Результат

Предоставить bounded log reads, literal search, opaque content refs и export сохранённого диапазона до фиксированного high watermark.

## Приёмка

Cursor привязан к session/generation/representation/filter; новые события не мешают завершить старый export. Range/command queries возвращают provenance/coverage. Original content и search проверяют ACL заново; arbitrary filesystem path input отсутствует. Expired refs дают явную ошибку.

## Проверка

NOT_RUN: большой лог, запись во время paging, cross-session cursor, invalid ranges, expired content, UTF-8 boundaries и export checksum. AT-07/08/10/13, TE-C04/05/07.
