# Формализовать MCP schemas и error contract

## Результат

Создать исполняемые JSON Schemas/Swift модели для tools из API contract, nullable evidence/state/coverage и bounded error envelopes.

## Приёмка

Все поля, enum, limits и additionalProperties правила определены; synthetic examples либо валидируются, либо заменены полными fixtures. JSON-RPC error отделён от tool failure и nonzero command result. Tool annotations не считаются ACL; clipboard-read side effect честно отмечен. Version negotiation согласован с SDK.

## Проверка

NOT_RUN: roundtrip всех tools, invalid target/extra keys/large payload, null vs zero, protocol versions и минимальный compatibility text projection без двойного output. AT-05/08/16/17, TE-C04/05/07.
