# Показать общий managed pane в обоих приложениях

## Результат

Запускать user attach-client к нужному pane в настоящем Terminal.app/Ghostty и подтверждать view binding до ввода.

## Приёмка

Пользователь видит ту же программу/вывод и может работать с ней, не отдельный лог viewer. Выбор app соблюдается. Closing last view приостанавливает агентский ввод без уничтожения shell; reopen/rebind только явный. Profile/font/theme не переписываются.
