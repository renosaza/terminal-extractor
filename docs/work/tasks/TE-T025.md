# SQLite metadata и сегментированный archive

## Результат

Создать versioned storage для sessions/commands/capture epochs/segments/gaps и private append-only файлы с offsets/checksums.

## Приёмка

Большой output не хранится одним DB value; writes bounded и упорядочены. Byte offset не путается с Unicode index. Миграции atomic с recovery, private permissions проверяются. DB/segment commit boundary задокументирован без обещания недоказанной zero-loss durability.

## Проверка

NOT_RUN: segment rollover, crash между file flush/DB commit, partial frame, disk full, invalid permissions и schema upgrade/rollback. AT-08/11/12, TE-C04/05/07.
