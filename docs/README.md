# Terminal Extractor: документация

Документация описывает **планируемый**, а не уже работающий продукт. Принятый пользователем scope: macOS, Terminal.app и Ghostty, подключение к существующей сессии или создание новой, команды со статусами, последняя команда с выводом, журнал конкретной сессии и экономия контекста.

[PRD](product/prd.md) задаёт продуктовые требования; архитектурные страницы — технические контракты; [карточки](work/README.md) — единственное состояние реализации. Прототипирование, runtime-тесты и измерения пока `NOT_RUN`.

Принцип доказательности: ограничение API не скрывается за обещанием универсальности. Старый scrollback не равен непрерывному журналу; получение tool response не означает завершения shell-команды; компактное представление не заменяет доступный оригинал.

Навигация: [index.md](index.md). Перед изменениями: [constraints.md](constraints.md).
