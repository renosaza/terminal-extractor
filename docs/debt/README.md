# Технический долг

Принятых долгов реализации пока нет: runtime не создан. Feasibility-вопросы, ограничения native API и продуктовые риски перечислены в [PRD](../product/prd.md) и задачах; они не объявляются выполненными компромиссами.

Запись debt добавляется только при реальном принятии компромисса: причина, риск, guardrails, разрешённый период/условия, точный all/any exit gate, related ADR и задачи удаления. Исследование неизвестного API само по себе не является accepted debt. Не создавать фиктивные записи ради заполнения каталога.
